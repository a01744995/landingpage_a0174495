# Guía rápida para colaboradores

- Trabaja desde una rama descriptiva (`feature/perfiles-equipo`, por ejemplo).
- Mantén el contenido de los integrantes en `data/team.ts`.
- Conserva los colores de marca definidos en `app/globals.css` bajo `:root`.
- Antes de abrir un pull request, ejecuta `npm run typecheck` y `npm run build`.
- No agregues datos personales, fotografías o enlaces de contacto sin autorización de cada integrante.
